# TrendGuard

TrendGuard is een WhatsApp bot voor het analyseren van aandelen en portfolios.  
Gebouwd met Python, Flask en yfinance.  

## Functies
- Analyse van ticker trends (MA50, MA200, RSI)
- WhatsApp integratie via Twilio
- Klaar voor uitbreiding naar portfolio analyse
